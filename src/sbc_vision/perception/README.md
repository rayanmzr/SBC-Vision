# Détection d'interface

Responsable principal : Saber. Voir [son rôle](../../../docs/roles/saber.md).

Ce module accueillera les adaptateurs OpenCV et détecteur affiné, les prétraitements et la normalisation vers `PerceptionResponse`. Il ne choisit pas les joueurs et ne clique pas. Les sorties conservent les coordonnées de la capture d'origine, y compris après redimensionnement ou recadrage.
