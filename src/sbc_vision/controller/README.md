# Contrôleur visuel

Responsable principal : Samy. Le contrôleur scripté consommera le JSON de perception, choisira une action puis vérifiera une nouvelle capture. Il doit avoir des modes observation et simulation avant toute exécution réelle, des limites d'étapes, une interruption utilisateur et des transitions explicites. Aucun pilote ni action réelle n'est présent dans le socle.
